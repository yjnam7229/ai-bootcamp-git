# 랭그래프의 핵심 개념
1. 상태 : 대화의 맥락을 기억, 도구를 통한 실행의 결과도 이 상태에 보관
2. 노드 : tool 이라는 데코레이터로 연결되어 있으면 그것이 노드가 된다, 작업의 주체자, 실제로 작업을 수행하는 작업자, 최신의 상태로 업데이트 
3. 엣지 : 노드와 노드 사이를 연결하는 선

모델 : 추론
엣지 : 다음에 수행해야 되는 정보

★ 체크포인터(checkpointer)
    메모리 기능을 담당하는 핵심 컴포넌트
    기존의 에이전트는 사용자 입력에 대해 에이전트가 실행되고 답변이 끝나면 모든 입출력 정보가 삭제됨 -> 체크포인터를 적용하면 입출력 정보 삭제 대신
    '상태 저장' 과정이 추가 -> 대화의 맥락이 유지 되면서 다시 대화를 이어나가고 새로운 질문에 답할 수 있게 됨
