■ SQLALCHEMY
DataBase와 ORM : FastAPI에서의 활용
    - FastAPI에서 데이터베이스 관리와 ORM(Object-Relational Mapping)의 사용은 웹 어플리케이션의 중요한 부분
    - ORM은 데이터베이스의 테이블을 객체로 매핑하여, 개발자가 SQL 쿼리 없이 데이터베이스를 쉽게 조작할 수 있게 함

FastAPI와 MySQL 연동 방법
    필요 라이브러리 설치 
        • pip install sqlalchemy==1.4.39
        • pip install pymysql==1.1.0

데이터베이스 모델 정의
    • SQLAlchemy를 사용하여 데이터베이스 모델을 정의
    • 각 모델은 데이터베이스의 테이블에 해당하며, 모델의 인스턴스는 테이블의 레코드를 나타냄        


FastAPI와 SQLAlchemy를 사용한 CRUD
    데이터 입력 : Create 작업(두가지 방안 존재)
    • 첫 번째 방안(Depends 사용)
        • 자동 세션 관리 : Depends를 통해 세션 생명주기 자동 관리
        • 재사용성 : get_db 함수 재사용 가능
        • 효율적 자원 관리

    • 두 번째 방안(sessionmaker 직접 사용)
        • 명시적 세션 생성 및 종료
    • 코드 명시성 증가
    • 예외 상황에서 세션 닫기를 놓칠 위험 존재      


■ 비동기 처리
여러 작업을 동시에 수행할 수 있는 프로그래밍 기법
하나의 작업이 완료될 때까지 기다리지 않고, 해당 작업이 백그라운드에서 진행되는 동안 다른 작업을 실행
어플리케이션의 전체 실행 시간을 단축 시키고 자원 사용의 효율성을 높일수 있음

■ async / await
    async def 비동기 함수를 정의하는 키워드, 이 함수는 호출 시 즉시 Future 객체를 반환하여
    이를 통해 다른 작업과 동시에 실행될 수 있음
       ■ Future 객체
        -비동기 연산의 아직 완료되지 않은 결과를 나타냄
        -연산의 상태를 추적하고, 완료시 결과에 접근할 수 있게 해줌
        -성공/실패 여부와 관계없이 최종 결과나 예외를 포함할 수 있음
        -연산 완료 후 실행될 콜백을 설정하는데 사용
