■ 로지스틱 회귀 - Classification
    Sigmoid 함수(S자 함수) : y값이 0.5를 기준으로 최대값이 1을 넘지 않는 함수, 최소값이 0에 수렴해가는 함수, 
    Sigmoid 함수에 적용해서 최종 출력값을 한번 더 적용하게 되어도 0 초과, 1 미만의 값을 가지는 함수 => 로지스틱 회귀
    기존 선형 모델 + Sigmoid 함수를 한번 더 적용 : 로지스틱 회귀

■ (인공) 신경망
    ReLU 함수(Rectified Linear Unit Function)

* 퍼셉트론과 신경망의 주된 차이는 활성화 함수의 차이    

활성화 함수(activation function) : h(a) : 
    입력 신호의 총합을 출력 신호로 변환하는 함수
    입력 신호의 총합이 활성화를 일으키는지를 정하는 역할

소프트맥스 함수의 특징
    소프트맥스 함수의 출력은 0에서 1사이의 실수, 출력의 총합은 1

소프트맥스 함수 : 입력 값을 정규화하여 출력(출력의 합 : 1)
    추론할 때는 일반적으로 소프트맥스 계층을 사용하지 않음.
