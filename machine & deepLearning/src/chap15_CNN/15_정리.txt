■ CNN(Convolution Neural Network) : 합성곱 신경망
    [ex] 4*4 데이터, 3*3 필터 -> 2*2 데이터 
    특성 맵(feature map) : CNN에서 합성곱 계산을 통해 얻은 출력 데이터

    합성곱 연산의 편향 
        편향은 항상 (1 x 1)만 존재


    패딩(padding) : 원본 데이터를 유지하면서 계산을 수행
    스트라이드 : 원하는 크기 만큼 이동, 스트라이드를 키우면 출력의 크기는 작아짐


CNN으로 이뤄진 네트워크 (합성곱 / 풀링 계층 추가) => 최종은 완전 연결 계층(Affine 계층)
    풀링(Pooling) : 가로, 세로 방향의 공간을 줄이는 연산, 채널의 갯수는 변하지 않는다, 입력의 변화에 영향을 적게 받는다
    2*2 최대 풀링을 스트라이드 2로 처리

    풀링 계층의 흐름
    입력 데이터 -> 전개 -> 최대값 -> reshape -> 출력 데이터


■ RNN(Recurrent Neural Network) : 순환 신경망
    순차적인 데이터를 입력 받아 결과값을 도출하는데 사용되는 딥러닝 모델

    - LSTM(Long Short-Term Memory)
