            - 가중치(기울기 값) 찾기    weight : 가중치
        1-2. 3x^2 - 5x + 2
    2. 회귀의 의미

■ k-최근접 이웃(k-Nearest Neighbor, kNN)
10등분 : 10번 반복 학습
         마지막 10번째 : 검증용 데이터로 사용, 나머지 데이터는 학습용 
         나머지 20%의 태스트 데이터로 
1. 학습된 데이터로 모델생성
2. 검증용 데이터로 성능을 평가(첫번째 데이터를 validation으로 추출)
3. 다시 학습(두번째 데이터를 validation 데이터로 사용하고 나머지 데이터는 학습용)

■ 서포트 벡터머신(Support Vector Machine, SVM) : 두 영역을 나누는데 최적의 경계선을 찾는 알고리즘
    1. 결정 경계(Decision Boundary) : 서로 다른 분류 값을 결정하는 경계    
    2. 서포트 벡터(Support Vector) : 결정 경계선과 가장 가까이 맞닿은 데이터 포인터(클래스의 점들)
    3. 마진(margin) : 서포트 벡터와 결정 경계선 사이의 거리
    
    SVM의 목표는 바로 이 마진을 최대로 하는 결정 경계를 찾는 것.
    서포트 벡터에서 마진이 최대가 되는 경계선 추적(기계학습) 예측 모델을 만든다

    ※ 벡터 : 데이터가 존재하는 공간    

  --------------------------------------------------------------------------------------------------
    ▲ 서포트 벡터머신 파라미터 튜닝 

    커널 : 차원을 변화시킴
    커널 트릭 : 차원을 변경해서 결정 경계를 찾는 방법  

    비용(C[cost]) : hyper 파라미터 
    과대 적합 : 훈련데이터에 최적화된 모델
    과소 적합 : 학습이 덜 되어 예측률이 떨어지는 모델

    서포트 벡터머신의 예측 모델 : RBF(Radial Basis Function) 커널(점을 무한한 차원으로 변환)

    튜닝(조절) 할 수 있는 값 : Hyper 파라미터
       1. C(cost, 비용) : 결정경계선의 마진을 결정하는 파라미터.
       2. gamma : 커널의 데이터포인트 표준 편차를 결정하는 조절 변수

       gamma 값의 변화에 따른 결정 경계는 과대 적합, 과소 적합
     
■ 의사결정 트리(Decision Tree) : 가장 큰 단점은 과대 적합에 빠질 위험이 높다
    엔트로피(Entropy) : 정보이론에서는 불확실성을 수치적으로 표현한 값
    정보 이득(Information gain) : 불확실성이 줄어든 정도, 질문 이전의 엔트로피에서 질문 후의 엔트로피를 뺀 차이 
       - 의사결정 트리의 최초 엔트로피는 1 이다
         엔트로피 값이 가장 작은 것을 먼저 배열 0

         ▲ 이진 분류
          지니계수(Gini coefficient) : 이진 분류로 나타날 경우 지니계수로 사용 할수 있음 P^2 + Q^2
            엔트로피 0 에 가까운 값 일수록 정보를 표현하기 용이하다
            지니계수가 높을수록 불순도가 높음
            지니계수와 엔트로피는 비례관계

■ 나이브(단순) 베이즈(Naïve Bayes) 
    ★★★독립적인 사건★★★ 이라는 조건이 붙어야 함(정확도가 높음, 예측 시간 단축), 독립적이지 않으면 정확도가 떨어짐
    독립 사건일 경우의 조건부 확률
    조건부 확률
        독립변수 
        종속변수

    결합 확률 : 두가지 이상의 사건이 동시에 발생하는 확률

    1. 가우시안 나이브 베이즈 알고리즘 : 데이터가 연속적인 값을 가지고 있는 경우
    2. 다항분포 나이브 베이즈 알고리즘 : 이산변수, 데이터가 범주(카테고리)값을 가지고 있는 경우, 시행 횟수의 의미가 중요
    3. 베르누이 나이브 베이즈 알고리즘 : 시행 횟수와 상관없음, 긍정/부정의 평가


■ 앙상블(Ensemble)
  배깅(bagging) : 부트스트랩(bootstrap) + 어그리게이팅(aggregating)

  1. 부트스트랩(bootstrap)
    여러 개의 분류 모델을 조합해서 더 나은 성능을 내는 방법
    서로 다른 학습 데이터로 학습시킨 후(부트스트랩), 
    동일한 테스트 데이터에 대한 서로 다른 예측값들을 투표를 통해(aggregating) 가장 높은 예측값으로 최종 결론을 내리는 기법

  2. 어그리게이팅(aggregating)

■ 부스팅(Boosting)
  1. XGBoost : 의사결정 알고리즘에 최적화(과적합 방지가 가능한 규제 포함) 
     오차의 원인 계산 -> 모델 학습 반복(첫번째, 두번째 ,,, 모델에서 오차 원인 계산 -> 더이상의 성능이 개선되지 안는다면 
     조기종료 제공)

■ 군집화(Clusting)
   데이터의 특징만으로 비슷한 데이터들끼리 모아 군집된 클래스로 분류함

■ 주성분 분석 알고리즘(Principal Component Analysis)  PCA
   고차원의 데이터를 저차원의 데이터로 차원 축소
   축소는 하지만 원 데이터가 소실되지 않게 유지, 정보의 유실이 가장 적은 라인을 찾는것
