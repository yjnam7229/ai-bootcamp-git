-접속 거부시
1. 상속 권한 제거
icacls .\xxx.pem /inheritance:r

2. 현재 사용자에게만 권한 부여
icacls .\xxx.pem /grant:r "$($env:USERNAME):(R)"

3. 권한 확인
icacls .\xxx.pem

4. 다시 접속 확인
ssh -i ".\xxx.pem" ec2-user@xxx.xxx.xxx.xxx



- docker 설치
ec2>sudo dnf update -y
ec2>sudo dnf install docker -y
ec2>sudo systemctl enable --now docker
ec2>sudo systemctl start docker
ec2>sudo usermod -aG docker ec2-user
ec2>exit
ec2>docker --version   # 재접속 후 확인


- compose v2 설치
ec2>mkdir -p ~/.docker/cli-plugins
ec2>curl -SL \
         https://github.com/docker/compose/releases/latest/download/docker-compose-linux-x86_64 \
         -o ~/.docker/cli-plugins/docker-compose

ec2>chmod +x ~/.docker/cli-plugins/docker-compose
ec2>docker compose version


- GHCR: 로컬(vs code 터미널)에서 ..\my_memo_app_mvc_docker\backend 폴더로 이동
ps>echo "GHCR_token" | docker login ghcr.io -u [깃허브계정] --password-stdin

- GHCR을 이용한 도커 컨테이너 배포하기(깃허브 컨테이너 레지스트리에 배포)
ps>docker build --platform linux/amd64 -t ghcr.io/[깃허브계정]/my-memo-app:1.0.0  .
ps>docker push ghcr.io/[깃허브계정]/my-memo-app:1.0.0


- ec2 인스턴스에 접속해서 역시 docker login 명령으로 깃허브 레지스트리에 접속-이미지 다운받기
ec2>echo "GHCR_token" | docker login ghcr.io -u [깃허브계정] --password-stdin
ec2>docker pull ghcr.io/[깃허브계정]/my-memo-app:1.0.0

- EC2 인스턴스에 사용할 수 있도록 docker-compose.yml 수정
ec2>mkdir -p ~/my_memo_app_mvc_docker
ec2>cd ~/my_memo_app_mvc_docker
ec2>nano docker-compose.yml   # ctl+o/enter/ctl+x
ec2>cat docker-compose.yml

ec2>docker compose up -d   # 컴포즈 실행하여 배포
