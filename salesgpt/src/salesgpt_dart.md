# SalesGPT 목적에 최적화된 DART API 정보 목록 및 전략

SalesGPT의 핵심 목적은 **DART 공시/재무 데이터를 활용해 고객사의 Pain Point를 정밀 진단하고, 맞춤형 B2B 제안서(docx)를 자동 생성하는 것**입니다.

이를 위해 수집 및 연동해야 하는 주요 DART API 목록과 활용 목적, 그리고 개발 및 연동 전략을 정리합니다.

---

## 1. SalesGPT 목적에 최적화된 DART API 정보 목록

| DART API | 가져올 주요 데이터 | SalesGPT 제안서 내 활용 목적 (Why) |
| :--- | :--- | :--- |
| **기업 개황**<br>`(company.json)` | • 대표자명, 업종코드(KSIC)<br>• 주소, 설립일, 홈페이지, 상장여부 | • **제안서 표지 및 고객사 개요 작성**<br>• 업종별 표준 솔루션 매핑 기준값 확보 |
| **단일회사 전체 재무제표**<br>`(fnlttSinglAcntAll.json)` | • 3개년 매출액, 영업이익, 당기순이익<br>• 재고자산, 매출채권, 판매비와관리비<br>• 유형자산(설비투자), 부채총계 | • **Pain Point 도출 및 B2B 제안 명분 산출**<br>  - 판관비 증가 ➔ 운영 효율화 솔루션 제안<br>  - 재고자산 증가 ➔ SCM/물류 관리 시스템 제안<br>  - 매출채권 증가 ➔ 채권 관리/리스크 솔루션 제안 |
| **사업보고서 주요정보**<br>`(alldata.json / 정기공시)` | • 주요 제품 및 서비스 매출 비중<br>• R&D(연구개발) 투자 현황<br>• 원재료 및 설비 가동률 | • **맞춤형 솔루션 적합성 검증**<br>  - 고객사의 주력 제품군/사업부에 맞춘 기술 제안<br>  - R&D 투자 비율에 따른 혁신 솔루션 수용성 평가 |
| **주요사항보고서 & 공시목록**<br>`(list.json)` | • 신규 시설투자 결정<br>• 타법인 주식 취득(M&A)<br>• 주요 계약 체결 / 유형자산 취득 | • **영업 기회(Trigger Event) 감지**<br>  - *"최근 OO공장 신설 공시에 따른 공정 자동화 제안"*<br>  - *"M&A 후 시스템 통합(ERP/IT) 제안 명분 확보"* |

## 2. 결론 및 우선순위 추천

1. **1순위 (필수)**: **`company.json` + `fnlttSinglAcntAll.json` (3개년)**
   - 제안서 기본 정보 구성 및 가장 중요한 **재무적 Pain Point(비용/효율성) 자동 진단**의 핵심 데이터입니다. 단년도가 아닌 3개년 트렌드를 추적해야 설득력 있는 분석이 가능합니다.
2. **2순위 (강력 추천)**: **`list.json` (주요 공시 목록)**
   - 최근 시설투자, M&A 등 **고객사의 최신 영업 호재/이슈**를 제안서 도입부에 언급하여 "우리 기업을 깊이 이해하고 있다"는 신뢰감을 부여합니다.
3. **3순위 (고도화)**: **`alldata.json` (사업보고서 주요 정보)**
   - 타겟 기업의 주력 제품 매출 비중과 R&D 현황을 파악하여 특정 사업부에 특화된 차별화된 B2B 제안서를 작성하는 데 활용합니다.

## 3. 제안서 연동 흐름 요약

```text
[DART API 데이터 수집]
  ├─ 기업 개황 (company.json)
  ├─ 3개년 재무 데이터 (fnlttSinglAcntAll.json)
  ├─ 사업보고서 주요정보 (alldata.json)
  └─ 최근 주요 공시 (list.json)
         │
         ▼
[SalesGPT 파이썬 분석 엔진]
  ├─ 재무 비율 및 문제점(Pain Point) 계산
  └─ 영업 기회 이벤트 감지 (시설투자, M&A 등)
         │
         ▼
[B2B 제안서 (python-docx) 자동 생성]
  ├─ 1. 제안 배경: 최신 공시 이슈 및 기업 개요
  ├─ 2. 문제 정의: 3개년 재무 데이터 기반 Pain Point
  └─ 3. 솔루션 제안: 문제 해결을 위한 맞춤형 B2B 제안
```
